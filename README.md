## About me

I'm a **full-stack software engineer** and an ENSA Agadir graduate, based in Casablanca, Morocco. I build secure, maintainable web applications with **Java, Spring Boot, React, and TypeScript**.

I'm currently completing my final month as a **Full-Stack Software Engineering Intern at VOID Agency**, where I am contributing to the modernization of business-critical HR processes for Barid Al-Maghrib. My work spans legacy-system analysis, backend APIs, frontend development, access control, and automated quality assurance.

- 🔭 Currently modernizing enterprise workflows from **J2EE to Spring Boot and React**
- 🔐 Experienced with **Keycloak, JWT, role-based access control, and secure APIs**
- 🧪 Focused on quality through **JUnit, Mockito, Vitest, Playwright, and SonarQube**
- 🌱 Interested in software architecture, system design, DevOps, and cybersecurity
- 💼 Open to **full-stack software engineering opportunities**

## Featured engineering projects

### 🏢 Enterprise HR Process Modernization — VOID Agency / Barid Al-Maghrib

Modernizing two business-critical HR processes from a legacy J2EE monolith to a **Spring Boot and React** architecture while preserving the existing Oracle schema and PL/SQL procedures. The work includes reverse-engineering complex business rules, rebuilding hierarchical approval workflows, implementing traceability, and managing authorization with Keycloak.

`Java 21` `Spring Boot 3` `React` `TypeScript` `Oracle` `PL/SQL` `Keycloak`

### 🔴 Badge and Airport Access Management — Royal Air Maroc

Built a full-stack application for badge and airport-access management, with dedicated administrator and employee experiences. Implemented authentication and role-based permissions through Keycloak.

`Spring Boot` `React` `PostgreSQL` `Keycloak`

### 🌐 Web Platform — Ralydev Technology

Developed a full-stack web platform during my PFA internship at Ralydev Technology. The solution combines a public-facing website, a JWT-secured client portal, and an administrative back office for content management and request tracking.

`Java` `Spring Boot` `React` `JWT`
